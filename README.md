# DrawShot — Mac 用 ZoomIt 風 画面描画ツール

Windows の ZoomIt みたいに、画面に直接描き込める Mac 用のツールです。
ミーティング中のデモや説明に使えます。メニューバー常駐型なのでいつでもすぐ呼び出せます。

---

## インストール（各自でビルド）

Xcode Command Line Tools が必要です（入ってなければ先に）：

```bash
xcode-select --install
```

`DrawShot.swift` と `build.sh` を同じフォルダに置いて実行：

```bash
bash build.sh
open DrawShot.app
```

起動するとメニューバーに ✏️ アイコンが出ます。

**Mac 起動時に自動で立ち上げたい場合**は、`DrawShot.app` を「アプリケーション」フォルダに移してから起動し、
メニューバーの ✏️ → 「ログイン時に起動」にチェックを入れてください。
（起動していないと ⌘2 は効きません）

**初回のスクショ保存時に「画面収録」の権限を求められます。**
システム設定 → プライバシーとセキュリティ → 画面収録 → DrawShot をオンにして再起動してください。

---

## 使い方

**⌘2** で描画モード ON/OFF（どのアプリを使っていても有効）

| 操作 | 動作 |
|---|---|
| ドラッグ | フリーハンドペン |
| ⌘ + ドラッグ | 四角形 |
| ⇧ + ドラッグ | 直線 |
| ⌥ + ドラッグ | 楕円 |
| R / G / B / Y / O / P / W / K | 色変更（赤・緑・青・黄・橙・ピンク・白・黒） |
| [ / ]　または　↓ / ↑ | 線を細く / 太く |
| ⌘Z | 1つ取り消し |
| E | 全消去 |
| ⌘S | 描き込み込みでデスクトップに PNG 保存 |
| Esc | 描画モード終了 |
